# Día 2 — Cómo aprende la Inteligencia Artificial

**Duración:** 30 minutos  
**Nivel:** Principiante  
**Estado:** Completado

## 1. Objetivo

Comprender cómo los modelos de aprendizaje automático aprenden patrones a partir de datos y cómo se utilizan para realizar predicciones.

## 2. Datos

Los datos son ejemplos o información utilizados para entrenar y evaluar modelos de IA. Pueden ser imágenes, textos, números o sonidos.

La calidad y variedad de los datos influyen en los resultados del modelo.

## 3. Entrenamiento

El entrenamiento es el proceso mediante el cual un modelo ajusta sus parámetros utilizando datos para aprender patrones.

En el aprendizaje supervisado, el modelo puede comparar sus predicciones con las respuestas esperadas y utilizar los errores para mejorar.

## 4. Inferencia

La inferencia consiste en utilizar un modelo entrenado para generar una respuesta o predicción.

Por ejemplo, cuando escribimos una pregunta en ChatGPT, normalmente el modelo utiliza sus parámetros entrenados y el contexto disponible para generar una respuesta.

## 5. Evaluación y generalización

Los modelos se evalúan con datos que no utilizaron durante el entrenamiento para comprobar cómo funcionan con ejemplos nuevos.

La generalización es la capacidad de aplicar los patrones aprendidos a situaciones nuevas.

Los datos insuficientemente variados pueden provocar errores en casos que el modelo no aprendió a reconocer bien.

## 6. Ejercicio práctico

Se presentan ejemplos donde las orejas puntiagudas y el maullido están asociados con gatos, mientras que las orejas caídas y el ladrido están asociados con perros.

Ante un ejemplo nuevo con orejas puntiagudas y maullido, la predicción esperada es gato.

Esta actividad demuestra cómo un modelo puede utilizar patrones aprendidos para clasificar un ejemplo nuevo. Sin embargo, una regla simplificada no garantiza que todas las predicciones sean correctas.

## 7. Reflexión personal

Aprendí que el entrenamiento y la inferencia son procesos diferentes. También comprendí que los modelos necesitan datos adecuados y pruebas con ejemplos nuevos para evaluar su rendimiento.

## 8. Próximos pasos

Estudiar cómo escribir instrucciones claras y eficaces para obtener mejores resultados con herramientas de inteligencia artificial.
