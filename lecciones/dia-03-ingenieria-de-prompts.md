# Día 3 — Ingeniería de prompts

**Duración:** 30 minutos  
**Nivel:** Principiante  
**Estado:** En progreso

## 1. Objetivo

Aprender a escribir instrucciones claras para obtener respuestas más útiles de una inteligencia artificial.

## 2. ¿Qué es un prompt?

Un prompt es una instrucción, pregunta o conjunto de indicaciones que proporcionamos a una IA.

La ingeniería de prompts consiste en diseñar y mejorar esas instrucciones para orientar los resultados hacia lo que necesitamos.

## 3. Componentes de un buen prompt

- **Rol:** indica qué función o perspectiva queremos que adopte la IA.
- **Tarea:** especifica lo que necesitamos.
- **Contexto:** proporciona información relevante sobre nuestra situación o nivel.
- **Formato y restricciones:** define cómo queremos la respuesta y qué condiciones debe respetar.

### Ejemplo

Actúa como un profesor de programación para principiantes. Estoy aprendiendo JavaScript y conozco las variables y las funciones. Explícame qué son los arrays con palabras sencillas, muestra dos ejemplos y termina con un ejercicio sin resolver.

## 4. Mejorar respuestas mediante iteraciones

Podemos mejorar una respuesta enviando instrucciones adicionales.

Por ejemplo:

1. Pedir una explicación de un concepto.
2. Solicitar una versión más sencilla si no lo entendemos.
3. Pedir ejemplos prácticos.
4. Solicitar un ejercicio para comprobar lo aprendido.

Este proceso permite ajustar las respuestas a nuestras necesidades.

## 5. Aplicación a la programación

Al utilizar IA para programar, podemos pedirle que:

- Explique un fragmento de código línea por línea.
- Identifique un error y explique cómo corregirlo.
- Proponga casos de prueba.
- Nos dé ejercicios sin mostrar inmediatamente la solución.

Es importante revisar y ejecutar el código para comprobar su funcionamiento.

## 6. Uso responsable

- Verificar la información importante.
- No compartir contraseñas, claves de API ni datos sensibles.
- Comprender el código generado antes de utilizarlo.
- No asumir que una instrucción detallada garantiza una respuesta correcta.

## 7. Ejercicio práctico

Crear un prompt para aprender el método `.filter()` de JavaScript.

El prompt debe incluir:

- Un rol de profesor para principiantes.
- Una explicación del método.
- Un ejemplo comentado.
- Un ejercicio práctico sin solución inmediata.

**Mi respuesta:**

Quiero que me expliques el método `.filter()` de JavaScript con un ejemplo claro, sin mostrarme la solución del ejercicio.

## 8. Pregunta de repaso

¿Cuál es la ventaja de especificar el rol, la tarea, el contexto y el formato en un prompt?

**Mi respuesta:**

Es importante especificar el rol, la tarea, el contexto y el formato para que la IA comprenda qué necesitamos, cuál es nuestro nivel de conocimiento y cómo queremos recibir la información. Así podemos obtener respuestas más útiles y aprender de manera más efectiva.

## 9. Reflexión personal

¿Qué aprendí hoy y cómo puedo aplicar la ingeniería de prompts para aprender programación?

**Mi reflexión:**

Aprendí que escribir instrucciones claras ayuda a obtener respuestas más útiles de la IA. Puedo aplicar esta habilidad para aprender JavaScript, comprender código y practicar sin depender de soluciones inmediatas.
