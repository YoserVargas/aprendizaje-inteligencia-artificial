
# Día 8: Desarrollo de un proyecto práctico con IA

**Estado:** Completado  
**Nivel:** Principiante  
**Duración:** 30 minutos

## 1. Objetivos

- Aprender a convertir una idea en un proyecto de programación.
- Definir el alcance inicial de una aplicación.
- Dividir un proyecto en tareas pequeñas.
- Utilizar IA para planificar y desarrollar código.
- Comprobar las funcionalidades antes de continuar.

## 2. De una idea a un proyecto

Una idea inicial puede ser demasiado general. Para convertirla en un proyecto debemos identificar el problema, definir la solución y establecer qué funcionalidades tendrá la primera versión.

El alcance define qué incluye el proyecto y qué dejamos para versiones posteriores.

## 3. Proyecto elegido: organizador de tareas

Mi objetivo es construir una aplicación sencilla que me ayude a organizar tareas cotidianas.

Utilizaré:

- HTML para la estructura.
- CSS para el diseño visual.
- JavaScript para la lógica y las interacciones.

### Funcionalidades iniciales

1. Añadir tareas.
2. Mostrar la lista de tareas.
3. Marcar tareas como completadas.

La primera versión será sencilla. No añadiré funcionalidades innecesarias antes de comprobar que las básicas funcionan.

## 4. Dividir el trabajo

El proyecto se desarrollará en pasos:

1. Crear la estructura de archivos.
2. Construir la interfaz básica.
3. Implementar la función para añadir tareas.
4. Mostrar las tareas en pantalla.
5. Permitir marcar tareas como completadas.
6. Probar cada funcionalidad y corregir errores.

## 5. Uso de la IA durante el desarrollo

La IA puede ayudarme a planificar, explicar código y proponer soluciones.

Debo pedir ayuda de manera concreta, comprender el código generado y comprobar sus resultados antes de continuar.

No debo considerar una funcionalidad terminada únicamente porque la IA haya generado el código.

## 6. Ejemplo inicial en JavaScript

```javascript
const tareas = [];

function agregarTarea(nombre) {
  tareas.push(nombre);
}

function mostrarTareas() {
  console.log(tareas);
}

agregarTarea("Estudiar JavaScript");
agregarTarea("Practicar programación");

mostrarTareas();
```

Este ejemplo permite añadir tareas a un array y mostrarlo en la consola. Todavía no constituye la aplicación completa con interfaz gráfica.

## 7. Actividad práctica

### Ejercicio 1: definir el proyecto

Mi respuesta: crear una aplicación sencilla que permita añadir tareas, mostrarlas y marcarlas como completadas.

Resultado: correcto.

### Ejercicio 2: trabajar por etapas

Mi respuesta: comprobar que la funcionalidad actual funciona y después continuar con la siguiente.

Resultado: correcto.

### Ejercicio 3: describir el proyecto a la IA

Mi propuesta: construir una aplicación con HTML, CSS y JavaScript para organizar tareas sencillas, avanzando paso a paso para entender el proceso y revisar el código.

Resultado: correcto. La petición define el objetivo, las tecnologías y la forma de trabajo.

### Pregunta final de repaso

Mi respuesta: probar la funcionalidad, comparar los resultados con lo esperado, corregir errores y continuar después.

Resultado: correcto.

## 8. Conclusiones

Aprendí que un proyecto debe tener un objetivo claro y un alcance inicial realista. También comprendí que dividir el trabajo en tareas pequeñas facilita el desarrollo y la depuración.

Utilizaré la IA como apoyo para aprender, pero revisaré y probaré cada funcionalidad antes de continuar.
