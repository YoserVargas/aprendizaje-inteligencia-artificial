## 1. Objetivos

- Identificar diferentes tipos de herramientas de IA.
- Elegir una herramienta según la tarea que necesito realizar.
- Comprender cómo integrar la IA en un flujo de trabajo.
- Revisar y probar los resultados generados por IA.

## 2. Tipos de herramientas de IA

### Asistentes conversacionales

Ejemplos: ChatGPT y Claude.

Sirven para aprender conceptos, resolver dudas, generar ideas, planificar tareas y explicar código.

### Asistentes de programación

Ejemplos: GitHub Copilot y Cursor.

Ayudan a escribir, completar, explicar y revisar código. Sus sugerencias deben comprobarse antes de utilizarlas.

### Generadores de imágenes

Ejemplo: Adobe Firefly.

Permiten generar imágenes e ilustraciones a partir de descripciones escritas.

### Herramientas de análisis de datos y documentos

Ayudan a resumir documentos, organizar información, analizar datos y encontrar patrones, según las funciones disponibles en cada herramienta.

## 3. ¿Cómo elegir una herramienta?

- Para entender un error de JavaScript: utilizar un asistente conversacional o de programación.
- Para crear una ilustración: utilizar un generador de imágenes.
- Para guardar el historial de cambios del proyecto: utilizar Git y GitHub.
- Para comprobar un programa: ejecutarlo y probar diferentes casos.

La herramienta debe elegirse según el resultado que necesito obtener.

## 4. Flujo de trabajo para programar con IA

1. Explicar el problema y pedir orientación a la IA.
2. Escribir o modificar el código en el editor, por ejemplo, VS Code.
3. Revisar el código para comprender qué hace.
4. Ejecutar el programa y probar distintos casos.
5. Corregir los errores encontrados.
6. Guardar los cambios con Git y subirlos a GitHub cuando estén listos.

La IA es una herramienta de apoyo; comprender el código sigue siendo responsabilidad del desarrollador.
