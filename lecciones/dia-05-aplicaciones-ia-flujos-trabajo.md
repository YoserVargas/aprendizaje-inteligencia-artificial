
# Día 5: Aplicaciones de IA y flujos de trabajo

**Estado:** Completado  
**Nivel:** Principiante  
**Duración:** 30 minutos

## 1. Objetivos

- Identificar aplicaciones prácticas de la inteligencia artificial.
- Comprender qué es un flujo de trabajo.
- Combinar la IA con otras herramientas.
- Aprender a verificar los resultados generados por IA.
- Aplicar estos conceptos a un problema de programación.

## 2. Aplicaciones prácticas de la IA

### Aprender y comprender conceptos

La IA puede explicar temas difíciles, proporcionar ejemplos y proponer ejercicios.

Ejemplo: pedir una explicación sencilla del método `.filter()` de JavaScript.

### Ayudar a programar

Puede explicar código, sugerir soluciones, ayudar a detectar errores y proponer pruebas.

Es necesario revisar el código generado antes de utilizarlo.

### Analizar información

Puede resumir documentos, organizar datos y ayudar a detectar patrones. Los resultados deben verificarse, especialmente cuando incluyen cálculos.

### Crear contenido

Puede ayudar a preparar borradores de textos, generar ideas, crear imágenes y elaborar presentaciones, dependiendo de la herramienta.

### Automatizar tareas

La automatización consiste en organizar pasos para reducir el trabajo manual. Puede utilizarse, por ejemplo, para clasificar solicitudes o preparar borradores de respuestas.

## 3. ¿Qué es un flujo de trabajo?

Un flujo de trabajo es una secuencia organizada de pasos para alcanzar un objetivo.

En un proyecto de programación, un flujo de trabajo puede ser:

1. Planificar el problema.
2. Pedir orientación a la IA cuando sea necesario.
3. Escribir el código en VS Code.
4. Ejecutar el programa y probar distintos casos.
5. Corregir los errores encontrados.
6. Guardar los cambios con Git y subirlos a GitHub.

Cada herramienta cumple una función diferente. La IA puede sugerir una solución, el editor permite escribir código, el entorno de ejecución permite comprobarlo y Git registra los cambios.

## 4. Cómo utilizar la IA sin depender de ella

Para aprovechar la IA como herramienta de aprendizaje:

1. Intentar comprender el problema.
2. Pedir una explicación o una pista.
3. Escribir o adaptar una solución.
4. Ejecutar el código.
5. Probar diferentes casos.
6. Investigar y corregir los errores.

Antes de utilizar código generado por IA, debo preguntarme:

- ¿Qué problema resuelve?
- ¿Cómo funciona?
- ¿Cómo puedo comprobar que funciona correctamente?

La IA sirve como apoyo, pero comprender y verificar el código sigue siendo responsabilidad del desarrollador.

## 5. Ejemplo práctico: filtrar productos

Objetivo: obtener únicamente los productos que cuestan menos de ₡5.000.

```javascript
const productos = [
  { nombre: "Cuaderno", precio: 1500 },
  { nombre: "Mochila", precio: 12000 },
  { nombre: "Lapicero", precio: 500 },
  { nombre: "Libro", precio: 6000 }
];
```

El trabajo consiste en definir el objetivo, crear una función que filtre los productos, ejecutar el código y comprobar que la mochila y el libro no aparezcan en el resultado.

No basta con que la IA genere una función: hay que verificar que cumpla la condición solicitada.

## 6. Actividad práctica

### Ejercicio 1: ordenar el flujo de trabajo

Mi respuesta: primero definir el objetivo y planificar la solución.

Resultado: correcto.

El orden general es planificar, programar, probar, corregir y guardar los cambios.

### Ejercicio 2: elegir la herramienta adecuada

1. Comprender `.filter()`: asistente de IA.
2. Escribir y modificar código: VS Code.
3. Comprobar resultados: ejecutar el código y realizar pruebas.
4. Conservar el historial de cambios: Git y GitHub.

Resultado: 4 de 4 respuestas correctas.

### Ejercicio 3: detectar un error

Situación: una función incluye un producto de ₡12.000 cuando solo debe incluir productos de menos de ₡5.000.

Mi respuesta: revisar la condición del filtro, ejecutar nuevas pruebas y corregir el error.

Resultado: correcto.

Aprendizaje: los resultados de la IA deben verificarse y los errores deben investigarse antes de aceptar una solución.

Pregunta: ¿Cuál es la mejor manera de utilizar la IA en un proyecto de programación?

Mi respuesta: utilizar la IA como apoyo, combinarla con las herramientas necesarias y comprobar que los resultados sean correctos.

Resultado: correcto.

## 8. Conclusiones

Aprendí que la IA tiene aplicaciones en el aprendizaje, la programación, el análisis de información, la creación de contenido y la automatización.

También comprendí que un flujo de trabajo organiza los pasos necesarios para resolver un problema. Combinar herramientas permite trabajar de manera más ordenada y comprobar los resultados.

La IA no debe sustituir mi propio razonamiento. Debo comprender, ejecutar y probar el código antes de utilizarlo.
